# simple-interest-calculator

## Description

A simple interest calculator project developed using Bash scripting. This project calculates simple interest based on the principal amount, rate of interest, and time period.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

## Features

- Accepts principal amount as input
- Accepts rate of interest as input
- Accepts time period as input
- Calculates simple interest
- Displays the calculated result

## Usage

Run the `simple-interest.sh` script in a Bash-compatible terminal.

```bash
bash simple-interest.sh
```

## Input

The script requires:

- Principal amount
- Rate of interest
- Time period

## Output

The script displays the calculated simple interest.
